# RC4 File Encryptor

Simple C++ program that encrypts and decrypts a file using the RC4 stream cipher.

## Files
- `rc4.cpp` – interactive encrypt / decrypt tool
- `test_rc4.cpp` – automatic test that encrypts then decrypts and verifies the result
- `Makefile` – build helpers
- `file.txt` – the file that will be encrypted/decrypted

## Build
```bash
make
